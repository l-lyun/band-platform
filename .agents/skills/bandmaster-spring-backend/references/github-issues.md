# GitHub Issues Reference

Use this when drafting GitHub issues for this repository.

Follow the existing `.github/ISSUE_TEMPLATE/feature.md` shape exactly:

```md
## 이슈에 대해 설명해 주세요.

## 작업 상세 내용

- [ ] TODO

## 참고할만한 자료(선택)
```

Style:

- Titles start with `[FEAT]`.
- Keep one issue broad enough to be meaningful, small enough to implement.
- Write descriptions in plain Korean.
- Avoid deep technical detail in the description.
- Put implementation hints in the checklist or references.
- Do not add `완료 조건` unless the user asks.

Recommended issue groups:

- `[FEAT] 백엔드 공통 기반 세팅`
- `[FEAT] 에러코드 및 예외 처리 구현`
- `[FEAT] Spring Security 기본 설정`
- `[FEAT] 회원 도메인 기본 모델 구현`
- `[FEAT] 이메일 회원가입 구현`
- `[FEAT] ID/PW 로그인 구현`
- `[FEAT] 로그인 5회 실패 시 24시간 잠금`
- `[FEAT] 토큰 인증 및 로그아웃 구현`
- `[FEAT] ID 찾기 구현`
- `[FEAT] PW 찾기 및 비밀번호 재설정 구현`
- `[FEAT] 개인 프로필 온보딩 구현`
- `[FEAT] 관심사 선택 온보딩 구현`
- `[FEAT] 소셜 로그인 확장 구조 설계`
- `[FEAT] 운영 확인용 Actuator 설정`
- `[FEAT] DB 마이그레이션 관리 방식 정리`
